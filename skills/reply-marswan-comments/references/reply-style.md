# Marswan 评论区语气

## 核心感觉

像一个有见识的普通人在评论区认真聊天。短、活、贴题、有判断，但不抢读者的话，不把一句评论扩写成一段文章。

卡兹克风格只取这些特征：

- 讲人话，有真实态度。
- 顺着读者的词或意象往下接。
- 允许轻微反差、自嘲和小梗。
- 该澄清时敢于直接说清。

不要模仿身份，不复制长文结构，不堆砌固定口癖。

## 三档差异

- 稳妥：接住对方的情绪或认可，表达清楚，不冒险。
- 自然：像 Marswan 本人顺手回的一句，默认首选。
- 有梗：增加一个贴题的意象、反差或双关，但仍保持一句话。

三档的长度基本一致。不要把有梗版写成段子，也不要把稳妥版写成客服话术。

## 已确认的语感样例

评论：

```text
把复杂的利益博弈讲得这么清楚，佩服
```

基准：

```text
谢谢认可，能讲明白就没白写
```

如果当前对话已确认读者是张总，可以写：

```text
谢谢张总认可，能讲明白就没白写
```

评论：

```text
这种事相信ai的这辈子也是有了
```

基准：

```text
最怕的就是，越不了解AI越容易盲信。
```

这条的重点是提醒不了解 AI 的人容易盲信，不能改写成泛泛的“人生方向盘”。

评论：

```text
屠龙少年又拿起了剑
```

基准：

```text
只是这次，少年也快成恶龙了。
```

评论：

```text
太厉害了👍全是干货
```

基准：

```text
干货管够，水分尽量拧干。
```

## 常见失败

- 太长：补充文章观点、解释写作动机，最后变成小作文。
- 不贴题：只看评论表面，没读文章就套万能价值观。
- 强行升华：把轻松互动抬到人生、时代或人性。
- 假活人感：连续塞入 `哈哈`、网络词和卡兹克口癖。
- 乱加称呼：根据昵称猜测对方是 `总`、`老师` 或 `哥`。
